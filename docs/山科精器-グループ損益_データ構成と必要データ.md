## 3. 現在のデータで確認できたロジック

### 3-1. 部門コード.xlsx がディメンション定義の本体

`部門構成 簡易連結` シートが、そのまま kpiee のディメンション階層になります。

```
連結
 └ 事業部門(大)   ファクトリー / エナジー / ヘルスケア / パートナー / 本社管理
    └ 事業部門(中) ファクトリーは (工作機械) と (油機・FA) に分岐
       └ 会社      山科精器 / ヤセック高知 / 平田精機 / ホープ電子 / サン・フレーム / 作新機工
          └ 部門    工作機械・熱交 共通・メディカル製造 … （山科精器は44部門）
```

- 内部取引の相殺行が階層内に明示的に置かれています（`ヤセック高知内部取引` `作新機工内部取引` `平田精機/ホープ電子内部取引` `サン・フレーム内部取引` `グループ内部取引`）。相殺は後工程ではなく、ディメンションのメンバーとして扱われています。
- シート内に「BSは会社単位で部門管理なし（BS項目の部門コードは自動作成で付与されたもので運用はされていない）」との注記があります。実データもこれと整合しており、部門が空欄の 9,885 行の内訳は買掛金 2,394 / 未払金 2,059 / 当座預金 1,619 … と BS 科目に集中しています。
- 会社ごとに階層の深さが違います（山科精器＝2階層、ヤセック高知＝1階層、サン・フレーム＝部門なし）。kpiee 側では NULL 階層を許容する設計が必要です。

### 3-4. 仕掛は月次ロールフォワード — 12ヶ月合計してはいけない

`期首仕掛工数棚卸高(製)` `期末仕掛工数棚卸高(製)` は毎月計上されています（山科精器で年間 127 件 / 118 件）。
12ヶ月を単純合計すると、ファクトリーで 838,007 千円となり、PDF の 52,010 千円と 16 倍ずれます。

月別に分解すると 4月計上分がそのまま年度の期首仕掛でした。

| セグメント | 4月計上の期首仕掛（仕訳） | PDF 期首仕掛 |
|---|---:|---:|
| ファクトリー | 52,010 | 52,010 |
| ヘルスケア | 2,167 | 2,167 |
| パートナー | 182 | 182 |

3 セグメントとも完全一致です。年度の期首仕掛＝4月計上分のみ、というルールが確定しました。

期末仕掛については 9月と3月に二重計上（半期・期末の調整仕訳）が入っており、単純に 3月分を採るだけでは一致しません（ファクトリー: 3月の期首130,400／期末87,188 に対し PDF は 43,594）。実地棚卸前の仮締データであることも影響しています。期末側の確定ロジックは C4 での確認事項とします。

### 3-5. 補助金/工数振替は符号が反転する

帳票の「補助金/工数振替」列は、製造原価報告書の `他勘定振替高` 分類（他勘定振替高・補助金収入）に対応します。
ヘルスケアで、仕訳集計 −6,578 千円 に対し PDF は +6,578 千円 と、絶対値が完全一致し符号だけが逆でした。ファクトリーも −14,043 対 +14,510 とほぼ同水準です。
帳票側は原価の控除項目としてプラス表記している、と読めます。

### 3-6. 本社管理の費用は各セグメントへ配賦されている

本社管理セグメントについて、仕訳では労務費 354 千円・製造経費 3,192 千円が計上されているのに対し、PDF はどちらも 0 です。
また一般管理費は 仕訳 71,515 千円 に対し PDF 64,303 千円（差 7,212）です。
勘定科目マスタには `部門配賦` `工管配賦` `管理人件費配賦` `管理費配賦` `販）販売費配賦` `販）販売人件費配賦` `本社配賦`（部門）が存在しており、配賦の仕組みが会計上に組み込まれています。
〔仮説〕帳票では本社管理の製造原価相当分を各事業セグメントへ寄せている。配賦基準（人数・売上比・工数など）は未入手です。

- 製番が両者の結合キーです。製番は `HBH2455003-1` のように「受注No + 枝番」の形を取ります。
- 社内工数行は 原価金額 = 作業時間 × 4,000円 で計算されています（2.83h → 11,320円 / 5.5h → 22,000円 など、確認した全行で一致）。労務費の社内単価は 4,000円/h の固定レートです。
- 手配コードで原価の種類が分かれます: 0100 社内機械設計 / 0200 機械設計外注 / 0300 社内電気設計 / 0500 機械部品購入 / 0600 電気部品購入 / 1000 一括外注加工 / 4000 社内加工 / 5000 社内組立 / 5400 社内電気調整 / 5800 出荷・梱包 / 8900 その他費用

〔仮説・未検証〕受注分類コードの上位2桁が部門系統（02=工機、03=熱交、04=油機、05=メディカル、06=弁研/バレル、08=水口工場）に対応しています。ただしこれは値の並びからの推測であり、対応表（D4）での確認が必要です。

## 4. kpiee 実装に向けた整理

### 4-1. 必要なマスタテーブル

### 4-2. ファクトテーブル

| テーブル | 元データ | 粒度 |
|---|---|---|
| 仕訳 | 各社 仕訳CSV | 1行 = 1仕訳明細。借方・貸方を縦持ちに正規化する（会社・日付・科目・部門・金額・貸借区分） |

仕訳の縦持ち変換が前提になります。マネーフォワード形式は 1 行に借方と貸方が同居しており、部門・補助科目・取引先も借方/貸方それぞれに列があるためです。

### 4-3. 集計ロジックとして実装すべきもの

1. 科目分類マッピング（3-2 の表）
2. 期首/期末仕掛の期間指定（12ヶ月合計ではなく期首月・期末月を採る、3-4）
3. 他勘定振替高の符号反転（3-5）
4. 販売費と一般管理費の切り分け（科目名の `販）` 接頭辞、3-2）
5. 内部取引の控除（3-3・ロジック未確定）
6. 本社管理費の配賦（3-6・基準未確定）
7. 会社別の文字コード・列名の吸収（3-9）

1〜4 は現在のデータだけで実装できます。5〜6 は C4 の入手待ちです。

## 6. 現時点の総括

- 山科精器単体の損益は、いただいた仕訳データと部門コード.xlsx だけで、労務費・製造経費・販管費について実測 0.1〜6% の精度で再現できました。一般管理費は完全一致です。会計データの構造としては、kpiee への移行に十分な粒度があります。

- TECHS の受注・原価明細は単体では完結しており（製番で結合可能・社内単価 4,000円/h が確定）、Q4 の対応表さえあれば製番別採算の可視化まで到達できます。
